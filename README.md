# 모카가든 · 나를 닮은 정원 생명체

태블릿용 워크숍 웹앱입니다. 기본 몸을 직접 빚어 동물 자화상을 만들고, 내 특징이 드러나는 동작을 녹화한 뒤 모카가든에서 고른 자리에 AR로 놓습니다.

[워크숍 웹앱 열기](https://boracles.github.io/moka-garden-ar/)

## 수업에서 사용하기

1. 아이패드 Safari에서 웹앱을 엽니다. 정원에서 본 조각과 자기 특징을 떠올리며 캐릭터 표면을 밀고 당깁니다. **뼈대로 움직여 보기**에서 연결 상태를 확인할 수 있습니다.
2. **앞 카메라 켜기**로 자세를 확인한 뒤 **3초 녹화**를 눌러 동작을 합니다. 다시 보거나 애니메이션을 포함한 3D 작품 파일(GLB)을 저장할 수 있습니다.
3. 정원에서 살 자리를 정합니다. **뒤 카메라로 정원 비추기**를 누르고 바닥을 천천히 훑습니다. 위치 추적이 준비됐다는 안내가 나오면 바닥을 터치해 캐릭터를 놓습니다. 위치, 크기, 방향을 바꿔 볼 수 있습니다.

앞 카메라 영상은 브라우저에서 MediaPipe로 처리합니다. 작품에 담기는 것은 3D 모델과 관절 애니메이션입니다. AR 배치는 현재 카메라 세션에 유지됩니다. 모카가든 현장에서 실제 수업용 iPad를 사용해 카메라 전환과 위치 추적을 확인해 주세요.

## 로컬 개발

```sh
npm ci
npm run dev
npm run build
```

웹앱 카메라 기능은 HTTPS나 localhost에서 사용할 수 있습니다. 실제 모바일 기기의 카메라와 AR을 함께 테스트할 때는 HTTPS로 배포한 주소를 사용합니다.

## 사용한 기술

- Three.js로 편집 가능한 캐릭터와 관절을 구성하고 GLB로 내보냅니다.
- MediaPipe Pose Landmarker로 동작을 추적합니다.
