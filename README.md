# 모카가든 · 움직이는 자화상

《완벽한 바나바》에서 이어지는 태블릿 워크숍입니다. 수업 이야기에서 실험실을 탈출한 생명체들이 모카가든에 자리 잡았습니다. 아이들은 자기 특징을 담아 생명체를 빚고, 동작과 기능을 붙여 정원에서 살 자리에 AR로 놓습니다.

[워크숍 웹앱 열기](https://boracles.github.io/moka-garden-ar/)

## 수업에서 사용하기

수업 전에 **교사용 QR 10장**에서 수업 날짜를 선택해 01–10번을 한꺼번에 인쇄하고, 학생에게 번호를 하나씩 배정합니다. 다른 날짜를 고르면 새 QR 10장이 생성됩니다.

1. 아이패드 Safari에서 웹앱을 엽니다. 점토 구에서 시작해 표면을 밀고 당기고 다듬습니다. 머리, 귀, 팔, 다리나 움직이는 점토를 붙여 원하는 모양으로 빚고 칠합니다. **좌우 대칭**은 기본으로 켜져 있습니다. 한쪽만 다듬으려면 붓 설정에서 끕니다. 옆에 한 개만 붙인 점토는 붙인 부위에서 편집합니다. **뼈대로 움직여 보기**에서 몸의 연결 상태를 확인할 수 있습니다. **예시 보기**에서는 완성 예시를 따로 돌려 볼 수 있습니다.
2. 머리·양팔·양다리를 붙이고 **동작 녹화**로 이동합니다. 캐릭터의 턱·손목·팔꿈치·무릎·가랑이에 색 마커를 맞춘 뒤 **다음 · 리깅 적용**을 누릅니다. 마커 위치에 맞춰 휴머노이드 뼈대를 만들고 점토 표면에 스킨 웨이트를 적용합니다. **앞 카메라 켜기**를 누르면 캐릭터가 내 몸짓을 실시간으로 따라 합니다. **3초 녹화**로 움직임을 저장하고 **다시 보기**로 확인합니다.
3. **기능 붙이기**에서 언제, 어느 부위가, 어떻게 움직일지 고릅니다. 화면 터치 또는 표식에 등장할 때를 골라 코·꼬리, 귀, 머리, 손에 반응을 붙일 수 있습니다. 코나 꼬리는 구부리는 동작을 직접 녹화할 수 있습니다. 만든 반응은 **내 반응 시험하기**에서 확인합니다.
4. **정원에 놓기**에서 수업 날짜와 배정받은 QR 번호를 입력하고 **QR 번호에 작품 저장**을 누릅니다. 인쇄한 표식을 정원의 평평한 곳에 놓고 **뒤 카메라로 QR 비추기**를 누르면 해당 작품이 나타납니다. QR의 네 모서리가 카메라에 들어와야 합니다.

작품은 현재 브라우저와 GLB 파일에 날짜와 번호별로 저장됩니다. 같은 기기에서는 저장 직후 기본 카메라로 QR 링크를 열어 관람 화면을 시험할 수 있습니다. 별도의 기기에서도 보이게 하려면 운영자가 GLB를 `public/works/YYYY-MM-DD/moka-garden-NN.glb`에 넣고 GitHub Pages에 배포합니다. 관객은 기본 카메라로 QR 링크를 열고, 웹앱에서 카메라를 켠 뒤 같은 QR을 비춥니다. 링크에서 날짜와 번호를 읽어 정확한 작품을 불러옵니다. **지난 작품 보기**에서는 선생님이 날짜를 골라 저장하거나 공개한 작품을 확인할 수 있습니다.

`2026-11-13`의 01–10번에는 관람 흐름을 바로 확인할 수 있는 테스트 작품이 있습니다. 실제 수업에서는 수업 날짜에 맞춰 새 QR을 준비하고 해당 날짜 폴더에 학생 작품을 배포합니다.

## 로컬 개발

```sh
npm ci
npm run dev
npm run build
```

웹앱 카메라 기능은 HTTPS나 localhost에서 사용할 수 있습니다. 실제 모바일 기기의 카메라와 AR을 함께 테스트할 때는 HTTPS로 배포한 주소를 사용합니다.

## 사용한 기술

- Three.js로 편집 가능한 캐릭터와 관절을 구성하고 GLB로 내보냅니다.
- MediaPipe Pose Landmarker로 동작을 추적합니다.
- jsQR로 뒤 카메라 영상에서 인쇄한 QR 표식의 모서리를 찾고, Three.js로 표식에 상대적인 위치와 방향을 계산합니다.
