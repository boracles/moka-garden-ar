# 모카가든 · 움직이는 자화상

《완벽한 바나바》에서 이어지는 태블릿 워크숍입니다. 수업 이야기에서 실험실을 탈출한 생명체들이 모카가든에 자리 잡았습니다. 아이들은 자기 특징을 담아 생명체를 빚고, 동작과 기능을 붙여 정원에서 살 자리에 AR로 놓습니다.

[워크숍 웹앱 열기](https://boracles.github.io/moka-garden-ar/)

## 수업에서 사용하기

1. 아이패드 Safari에서 웹앱을 엽니다. 점토 구에서 시작해 표면을 밀고 당기고 다듬습니다. 머리, 귀, 팔, 다리나 움직이는 점토를 붙여 원하는 모양으로 빚고 칠합니다. **뼈대로 움직여 보기**에서 몸의 연결 상태를 확인할 수 있습니다. **예시 보기**에서는 완성 예시를 따로 돌려 볼 수 있습니다.
2. **뼈대 맞추기**를 열어 팔꿈치와 무릎에 점이 오도록 위치를 조절합니다. 이때 팔과 다리의 점토가 관절을 따라 접히도록 연결됩니다. **앞 카메라 켜기**로 자세를 확인한 뒤 **3초 녹화**를 눌러 몸 동작을 저장합니다.
3. **기능 붙이기**에서 버튼으로 움직일 부분, 소리, 녹화한 동작을 고릅니다. 움직이는 점토는 위·앞·옆·뒤 중 한 곳에 붙여 코나 꼬리처럼 빚을 수 있습니다. **구부리는 동작 3초 녹화**를 누르고 슬라이더를 움직이면 점토가 여러 마디에서 구부러지는 동작이 저장됩니다. 녹화한 몸 동작과 점토 동작은 3D 작품 파일(GLB)에 함께 담을 수 있습니다.
4. 정원에서 살 자리를 정합니다. **뒤 카메라로 정원 비추기**를 누르고 바닥을 천천히 훑습니다. 위치 추적이 준비됐다는 안내가 나오면 바닥을 터치해 생명체를 놓습니다. 붙인 기능을 써 보고 위치, 크기, 방향을 바꿀 수 있습니다.

앞 카메라 영상은 브라우저에서 MediaPipe로 처리합니다. 작품에 담기는 것은 3D 모델과 관절 애니메이션입니다. AR 배치는 현재 카메라 세션에 유지됩니다. 모카가든 현장에서 실제 수업용 iPad를 사용해 카메라 전환과 위치 추적을 확인해 주세요.

## 로컬 개발

```sh
npm ci
npm run dev
npm run build
```

웹앱 카메라 기능은 HTTPS나 localhost에서 사용할 수 있습니다. 실제 모바일 기기의 카메라와 AR을 함께 테스트할 때는 HTTPS로 배포한 주소를 사용합니다.

## 사용한 기술

- Three.js로 편집 가능한 캐릭터와 관절을 구성하고 GLB로 내보냅니다.
- MediaPipe Pose Landmarker로 동작을 추적합니다.
