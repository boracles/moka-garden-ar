# 저마다의 완벽함

《완벽한 바나바》의 마지막에 바나바와 친구들이 자리 잡은 공원을 모카가든으로 상상하는 태블릿 워크숍입니다. 아이들은 하이메 아욘의 조각에서 귀, 코, 자세를 관찰합니다. 좋아하는 일이나 자주 하는 행동을 몸의 모양과 움직임으로 표현하고, 완성한 ‘또 다른 나’를 정원에 AR로 놓습니다.

[워크숍 웹앱 열기](https://boracles.github.io/moka-garden-ar/)

## 수업에서 사용하기

수업 전에 **교사용 QR 10장**에서 수업 날짜를 선택해 01–10번을 한꺼번에 인쇄하고, 학생에게 번호를 하나씩 배정합니다. 같은 날짜의 학생용 링크를 수업 기기에서 엽니다. 다른 날짜를 고르면 새 QR 10장이 생성됩니다.

1. 아이패드 Safari에서 웹앱을 엽니다. **부풀리기**에서 점토 표면을 문질러 볼록하게 또는 오목하게 만듭니다. **잡아당기기**로 점토를 잡고 원하는 방향으로 끕니다. **다듬기**는 표면을 부드럽게 합니다. 점토가 없는 화면을 드래그하면 캐릭터가 돌아갑니다. **점토 붙이기**에서 귀·코·꼬리·손·발이나 자유 점토를 붙입니다. 기본 색이나 직접 고른 색으로 칠할 수 있습니다. **좌우 대칭**은 기본으로 켜져 있습니다. **뼈대로 움직여 보기**로 기본 동작을 확인하고, **예시 보기**에서 완성 예시를 볼 수 있습니다.
2. **동작 녹화**에서 캐릭터의 턱·손목·팔꿈치·무릎·가랑이에 색 마커를 맞춘 뒤 **다음 · 리깅 적용**을 누릅니다. 마커 위치에 맞춰 휴머노이드 뼈대를 만들고 점토 표면에 스킨 웨이트를 적용합니다. **앞 카메라 켜기**를 누르면 캐릭터가 내 몸짓을 실시간으로 따라 합니다. **3초 녹화**로 움직임을 저장하고 **다시 보기**로 확인합니다.
3. **기능 붙이기**에서 언제, 어느 부위가, 어떻게 움직일지 고릅니다. 화면 터치 또는 표식에 등장할 때를 골라 반응을 붙일 수 있습니다. 코, 꼬리, 자유 점토의 구부리는 동작은 부위별로 녹화할 수 있습니다. 만든 반응은 **내 반응 시험하기**에서 확인합니다.
4. **정원에 놓기**에서 수업 날짜와 받은 QR 번호를 확인하고 **작품 등록하기**를 누릅니다. **QR 테스트하기**에서 같은 QR을 비춥니다. 반응을 터치로 정했다면 화면의 캐릭터를 터치합니다. 전신 동작이 한 차례 재생되고 추가한 반응이 끝나면 **작품 확정**을 누릅니다. 확정한 작품이 온라인으로 저장되면 화면에 **완료**가 표시됩니다.

관객은 기본 카메라로 QR 링크를 열고, 웹앱에서 카메라를 켠 뒤 같은 QR을 비춥니다. 웹앱이 QR에 연결된 공개 작품을 불러와 학생이 녹화한 동작과 추가한 반응을 재생합니다. 작품은 날짜와 번호로 각각 저장됩니다. **지난 작품 보기**에서도 날짜를 골라 해당 QR을 확인할 수 있습니다.

`2026-11-13`의 01–10번에는 관람 흐름을 확인할 수 있는 테스트 작품이 있습니다. 같은 QR에 학생이 작품을 확정하면 공개된 학생 작품이 표시됩니다.

## 온라인 작품 저장소 연결

Cloudflare Workers에서 `wrangler.toml`의 Worker를 배포합니다. Worker의 `CLASS_SECRET` 비밀 값에는 32자 이상의 임의 문자열을 사용합니다. 같은 값을 로컬 환경 변수에 넣어 `node server/class-link.mjs YYYY-MM-DD`를 실행하면 수업 기기용 링크가 생성됩니다. 이 링크는 학생에게만 공유하고, 인쇄하는 QR에는 관람 링크를 그대로 사용합니다.

Worker 주소를 프런트엔드 빌드 환경 변수 `VITE_MOKA_PUBLICATION_URL`에 설정하고 GitHub Pages에 배포합니다. 해당 수업 링크에서 처음 확정한 작품이 그 날짜와 번호에 저장되며, 같은 파일을 재전송할 수 있습니다. 프런트엔드는 서버 저장을 확인한 뒤 **완료**를 표시합니다.

## 로컬 개발

```sh
npm ci
npm run dev
npm run build
```

웹앱 카메라 기능은 HTTPS나 localhost에서 사용할 수 있습니다. 실제 모바일 기기의 카메라와 AR을 함께 테스트할 때는 HTTPS로 배포한 주소를 사용합니다.

## 사용한 기술

- Three.js로 편집 가능한 캐릭터와 관절을 구성하고 GLB로 내보냅니다.
- MediaPipe Pose Landmarker로 동작을 추적합니다.
- jsQR로 뒤 카메라 영상에서 인쇄한 QR 표식의 모서리를 찾고, Three.js로 표식에 상대적인 위치와 방향을 계산합니다.
